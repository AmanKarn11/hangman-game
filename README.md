# Hangman Game (Python)

A simple text-based Hangman game built using Python. The player has to guess a hidden word one letter at a time within a limited number of attempts.

---

## Features
- Random word selection from a predefined list
- Tracks guessed letters
- Limited attempts (6 chances)
- Simple console-based gameplay

---

## Concepts Used
- loops (while loop)
- conditionals (if-else)
- strings
- lists
- random module

---

## How to Run

```bash
python hangman.py
